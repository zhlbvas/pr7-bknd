# ПР7 — Тур-гид по Астане

## Описание проекта

Тур-гид по Астане — веб-приложение для просмотра достопримечательностей столицы Казахстана. Проект создан в рамках практической работы №7 по подключению облачной базы данных MongoDB.

## Используемые технологии

- Node.js
- Express.js
- EJS
- MongoDB Atlas
- HTML и CSS
- dotenv

## Возможности

- Просмотр достопримечательностей Астаны.
- Получение данных из облачной базы MongoDB.
- Добавление новых достопримечательностей через форму.
- Проверка обязательных полей формы.
- Обработка ошибок при работе с базой данных.

## Структура проекта

- `server.js` — сервер и маршруты приложения.
- `db.js` — подключение к MongoDB.
- `test-db.js` — проверка подключения.
- `views/` — EJS-шаблоны страниц.
- `public/` — стили, скрипты и изображения.
- `.env` — строка подключения к базе данных.
- `.gitignore` — исключение секретных файлов из Git.

## Установка и запуск

1. Склонируйте репозиторий.
2. Установите зависимости:

   ```bash
   npm install
   ```

3. Создайте файл `.env` и добавьте строку подключения:

   ```env
   MONGODB_URI=ваша_строка_подключения
   ```

4. Проверьте подключение:

   ```bash
   node test-db.js
   ```

5. Запустите приложение:

   ```bash
   npm start
   ```

6. Откройте в браузере `http://localhost:3000`.

## База данных

Используется облачная MongoDB Atlas.

- База данных: `astana_guide`
- Коллекция: `places`

Данные достопримечательностей хранятся в облаке и загружаются при открытии главной страницы.

## Безопасность

Строка подключения хранится в `.env`. Этот файл исключён из Git с помощью `.gitignore` и не должен публиковаться в репозитории.

## Практическая работа №7

Цель работы — заменить хранение данных в `data.json` облачной базой данных, реализовать чтение и сохранение записей, а также обработку ошибок подключения.
